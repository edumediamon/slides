# PowerPoint output

Read this reference only when the user requests PPTX output.

1. Create and verify the standalone HTML deck first. Use its slide order, wording, theme palette, and speaker notes as the source for the PowerPoint version.
2. Use an available presentation-authoring tool or an already installed PPTX library. Check the environment before choosing a library; obtain confirmation before adding a production dependency to the user's project.
3. Use 16:9 slides, matching typography and spacing. Keep text, shapes, tables, and simple charts editable. Embed supplied images and include useful alternative text. Record font substitutions.
4. Transfer speaker notes. Translate browser-only interactions into explicit question and answer slides or static states, and explain that limitation. Preserve source facts and labels.
5. Save `presentation.pptx` or the requested filename. Render and inspect slides when supported. Check text clipping, slide count, element placement, and note transfer.
6. Deliver the HTML and PPTX with the actual verification results. Archive/XML inspection confirms structure only; opening the file in PowerPoint is a separate check. If PPTX generation is unavailable, state that limitation and deliver the completed HTML.
