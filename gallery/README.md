# make-slide 테마 카탈로그 / Theme Catalog

11개 테마와 4개 레이아웃을 GitHub에서 선택합니다. 별도 `gallery/index.html` 없이 이 Markdown 문서를 카탈로그로 사용하며, GitHub Pages의 첫 화면도 같은 문서로 만듭니다.

**미리보기**는 GitHub Pages가 배포된 후 작동합니다. **디자인 가이드**와 **HTML 소스**는 GitHub에서 바로 읽을 수 있습니다. HTML 파일은 GitHub 파일 화면에서 실행되지 않으므로 미리보기를 사용하거나 다운로드해 브라우저에서 여세요.
