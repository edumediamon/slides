디스크 파티션 관리 & 볼륨 설정

1. Windows 관리 도구의 개요
• 시스템, 하드웨어, 스토리지, 이벤트 로그 등 고급 시스템 설정을 직접 제어하는 관리 콘솔
2. 디스크 관리 (Disk Management) 핵심 기능 ★
• 경로: [컴퓨터 관리] ➔ [저장소] ➔ [디스크 관리]

• 드라이브 문자(C:, D:) 변경 및 포맷 수행

TOPIC 22 • 작업 관리자 (TASK MANAGER) ★

시스템 제어 & 수행 불가 오답 함정

1. 작업 관리자 실행 단축키 & 주요 기능
• 단축키: Ctrl + Shift + Esc
• 실행 중인 응용 프로그램 및 프로세스 확인
• 응답 없는 프로그램 강제 종료, 시스템 종료/재시작 제어
• CPU, 메모리, 디스크, 네트워크 성능 실시간 모니터링
2. 시험 출제 1순위: 작업 관리자에서 '할 수 없는 것' ★
• 1. 실행 중인 앱의 실행 순서 변경 불가!
• 2. 드라이브의 전체/여유 용량 확인 불가! (디스크 점유율 %만 표시)
📊 작업 관리자 기능 O / X 판별표
기능 항목 가능 여부
응답 없는 프로그램 강제 종료 (작업 끝내기) O (가능)
CPU, RAM, GPU 리소스 사용량 모니터링 O (가능)

TOPIC 23 • 레지스트리 (REGISTRY)

시스템 통합 DB & regedit 편집기

1. 레지스트리의 정의 (암기 필수)
• 컴퓨터에 설치된 모든 하드웨어와 소프트웨어의 실행 정보를 한곳에 모아 관리하는 계층적 데이터베이스
• 사용자 프로필, 설치된 앱, 드라이버 설정 등 전반적인 환경 정보 수록
2. 레지스트리 편집기 실행 방법
• 단축키: + R (실행 창 호출)
• 명령어 입력: regedit 입력 후 Enter ↵
3. 주의 사항
• 레지스트리 수정 오류 시 시스템 부팅 불가 등 치명적 손상이 발생할 수 있으므로 사전에 백업(내보내기) 권장
🗄️ 레지스트리 계층 구조 시뮬레이터
📁 컴퓨터 (Computer)
  ├─ 📂 HKEY_CLASSES_ROOT (파일 확장자 연결 정보)
  ├─ 📂 HKEY_CURRENT_USER (현재 로그인한 사용자 환경)
  ├─ 📂 HKEY_LOCAL_MACHINE (하드웨어/소프트웨어 전체 정보)
  ├─ 📂 HKEY_USERS (시스템의 모든 사용자 계정 프로필)
  └─ 📂 HKEY_CURRENT_CONFIG (현재 디스플레이/하드웨어 구성)
💡 기출 지문 정답: "컴퓨터 하드웨어와 소프트웨어의 실행 정보를 보관하는 계층적 데이터베이스 편집 명령어는 regedit이다."
TOPIC 24 • 네트워크 (NETWORK)

TCP/IP 4대 요소 & DHCP 동적 할당

1. TCP/IP 필수 4대 구성 요소 ★
• 1. IP 주소: 네트워크 상에서 내 컴퓨터를 식별하는 고유 주소
• 2. 서브넷 마스크: 네트워크 ID와 호스트 ID를 구분하는 마스크
• 3. 기본 게이트웨이: 다른 네트워크(외부 인터넷)로 나가는 출입문 라우터
• 4. DNS 서버 주소: 문자 도메인 이름을 숫자 IP 주소로 변환
2. DHCP (동적 호스트 구성 프로토콜)
• IP 주소를 수동 입력하지 않고 자동으로 동적 IP 주소를 할당받는 프로토콜
🌐 TCP/IP IPv4 속성 대화상자 매핑
설정 항목 실제 설정 예시 및 역할
IP 주소 192.168.0.15 (단말 식별 주소)
서브넷 마스크 255.255.255.0 (네트워크 분할 규격)
기본 게이트웨이 192.168.0.1 (외부 인터넷 관문)
기본 DNS 서버 168.126.63.1 (도메인 ➔ IP 변환)
💡 기출 지문 정답: "인터넷에 정상 접속하기 위한 TCP/IP 4대 요소는 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 주소이다."
TOPIC 25 • DOS 명령어 ★최다 빈출

네트워크 진단 3대 핵심 명령어

1. Ping (연결 상태 & 응답 점검) ★
• 원격지 컴퓨터와의 네트워크 연결 상태 점검
• 원격지 IP/도메인, 전송 패킷의 손실률 및 응답 시간(ms) 표시
2. Ipconfig (현재 PC 네트워크 정보 확인) ★
• 현재 내 컴퓨터의 IP 주소, 서브넷 마스크, 기본 게이트웨이, MAC 주소 확인
• ipconfig /all 명령으로 모든 세부 네트워크 어댑터 정보 출력
3. Tracert (경로 추적 라우팅) ★
• 목적지까지 패킷이 거쳐가는 네트워크 경로(라우터) 추적
⚡ 네트워크 DOS 3대 명령어 완벽 비교
명령어 핵심 키워드 점검 대상 및 시험 정답
Ping 연결 상태 점검 원격지 패킷 전송 손실률 및 응답 시간 측정
Ipconfig 내 PC 정보 확인 IP 주소, 서브넷 마스크, 게이트웨이, MAC 확인
Tracert 경로(라우팅) 추적 목적지 도달까지 거치는 경유 라우터 구간 추적
💡 기출 지문 정답: "원격지 컴퓨터의 네트워크 연결 상태와 신호 손실률을 점검할 때 사용하는 명령어는 Ping이다."
TOPIC 26 • 컴퓨터의 개념 (CONCEPT)

Data ➔ Information & 5대 핵심 기능

1. 컴퓨터의 정의 (정보 처리 시스템)
• 자료(Data) 입력 ➔ 프로그램 명령어 처리 ➔ 정보(Information) 출력
• 자료(Data): 관찰/측정을 통해 얻은 가공되지 않은 순수 사실
• 정보(Information): 자료를 목적에 맞게 가공하여 의미를 부여한 결과물
2. 컴퓨터의 5대 장치
• 입력 기능: 키보드, 마우스 등을 통해 데이터 입력
• 제어 기능: 모든 장치의 동작을 지시하고 감독
• 기억(저장) 기능: 주기억장치 및 보조기억장치에 데이터 보관
• 연산 기능: 산술 연산(+,-,*,/) 및 논리 연산(AND, OR, NOT)
• 출력 기능: 모니터, 프린터 등으로 처리 결과 표시
⚙️ 컴퓨터의 6대 주요 특징
자동성
프로그램에 의해 자동 처리
정확성
올바른 자료·명령에 따라 정확히 처리
신속성
초고속 고성능 처리
호환성
기기 및 데이터 상호 호환
대량성
방대한 데이터 처리 및 저장
범용성
다양한 응용 분야에 활용
GIGO (Garbage In, Garbage Out)
올바른 입력이 들어가야 올바른 출력이 도출됨
💡 포인트: 컴퓨터의 5대 장치는 입력, 출력, 기억, 연산, 제어 장치입니다.
TOPIC 27 • 발전사 (HISTORY) ★

초기 계산기 & 세대별 특징 5단계

1. 초기 전자식 계산기 4대 공식 ★
• 에니악 (ENIAC): 최초의 전자계산기, 외부 프로그램 방식
• 에드삭 (EDSAC): 최초의 프로그램 내장 방식 도입
• 유니박 (UNIVAC-I): 최초의 상업용 전자계산기
• 에드박 (EDVAC): 폰 노이만, 프로그램 내장 방식 완성, 2진법 체계
2. 세대별 주요 소자 및 처리 방식
• 1세대: 진공관 ➔ 일괄 처리
• 2세대: 트랜지스터(TR) ➔ 온라인 실시간 처리
• 3세대: 집적회로(IC) ➔ 시분할 처리 (TSS)
• 4세대: 고밀도집적회로(LSI) ➔ 분산 처리 시스템
• 5세대: 초고밀도(VLSI) ➔ 인공지능, 전문가시스템, 퍼지이론
🕰️ 컴퓨터 1~5세대 발전 요약 매트릭스
세대 주요 소자 대표 처리 방식 및 특징
1세대 진공관 일괄 처리 (Batch Processing)
2세대 트랜지스터 (TR) 온라인 실시간 처리 (Real-time)
3세대 집적회로 (IC) 시분할 처리 (TSS), 다중 프로그래밍
4세대 고밀도 (LSI) 분산 처리 시스템 (Distributed)
5세대 초고밀도 (VLSI) 인공지능(AI), 퍼지이론, 음성인식, DSS
💡 기출 지문 정답: "3세대의 대표적 특징은 집적회로(IC)를 사용하고 시분할 처리(TSS)를 도입한 것이다."
TOPIC 28 • 컴퓨터 분류 ★최다 빈출

디지털 컴퓨터 vs 아날로그 컴퓨터

1. 디지털 컴퓨터 (Digital) — 범용 PC
• 취급 데이터: 셀 수 있는 이산 데이터 (숫자, 문자)
• 회로 & 연산: 논리 회로 / 산술 및 논리 연산
• 정밀도 & 속도: 필요한 한도까지 무제한 정밀 / 상대적 느림
• 기억장치 & 프로그래밍: 반드시 필요함 / 범용성
2. 아날로그 컴퓨터 (Analog) — 계측용
• 취급 데이터: 연속적인 물리량 (전류, 온도, 속도)
• 회로 & 연산: 증폭 회로 / 미적분 연산
• 정밀도 & 속도: 제한적 정밀도(0.01%) / 연산 속도 빠름
• 기억장치 & 프로그래밍: 필요 없음 / 특수 목적용
⚖️ 디지털 vs 아날로그 완전 정복 비교표
비교 항목 디지털 컴퓨터 아날로그 컴퓨터
취급 데이터 셀 수 있는 데이터(숫자/문자) 연속적 물리량(전류/온도)
구성 회로 논리 회로 증폭 회로
주요 연산 산술 및 논리 연산 미적분 연산
연산 속도 상대적으로 느림 빠름
정밀도 필요한 한도까지 정밀 제한적 (약 0.01%)
기억/프로그램 필요함 필요 없음
💡 기출 지문 정답: "디지털 컴퓨터는 논리 회로를 사용하며 산술 및 논리 연산을 하고 필요한 한도까지 정밀도를 높일 수 있다."
TOPIC 28 • 목적 & 규모 분류

하이브리드 & 휴대용 컴퓨터 형태

1. 데이터 조합 및 사용 목적에 따른 분류
• 하이브리드 컴퓨터: 디지털과 아날로그의 장점만을 결합한 컴퓨터
• 전용 컴퓨터: 특정 목적(군사, 제어 등)에 한정된 특수 목적용
• 범용 컴퓨터: 다양한 분야에서 다목적으로 사용하는 컴퓨터
2. 규모 및 성능에 따른 분류
• 마이크로(개인용) ➔ 워크스테이션 ➔ 소형(미니) ➔ 메인프레임(대형) ➔ 슈퍼 컴퓨터
3. 개인용 컴퓨터의 휴대용 형태 분류
• 데스크톱, 랩톱(무릎), 노트북, 팜톱(손바닥), 태블릿PC
• 웨어러블 컴퓨터: 소형화·경량화되어 신체나 옷에 착용하는 컴퓨터

KILLER TRAP • PART 1

🎯 킬러 기출 함정 플립카드 ①

💡 플립 카드 학습 안내
• 우측 카드를 클릭하면 카드가 180도 회전하며 O/X 정답 및 기출 해설이 나타납니다.
• 시험 직전 실전 감각을 끌어올리기 위한 최고난도 OX 훈련입니다.
체크 포인트
• Q1: 작업 관리자에서 앱 실행 순서 변경 가능 여부
• Q2: 레지스트리 편집기 실행 명령어
• Q3: Ping과 Tracert의 역할 구별
Q1. 작업 관리자의 앱 실행 순서 변경
"작업 관리자 창에서는 현재 실행 중인 프로그램들의 실행 순서를 사용자가 임의로 재배치하여 변경할 수 있다." (O / X?)
정답: X (실행 순서 변경 절대 불가!)
작업 관리자에서는 프로세스의 강제 종료와 모니터링만 가능하며, 실행 순서 변경은 할 수 없습니다!
Q2. 레지스트리 실행 명령어
"Windows 레지스트리 편집기를 실행하려면 [실행] 창에 'sysedit'을 입력해야 한다." (O / X?)
정답: X (정답은 regedit!)
레지스트리 편집기 실행 명령어는 regedit 입니다!
Q3. Ping 명령어의 주된 역할
"Ping 명령어는 원격지 컴퓨터까지의 라우팅 경로를 단계별로 추적할 때 사용된다." (O / X?)
정답: X (경로 추적은 Tracert!)
경로 추적은 Tracert이며, Ping은 원격지 연결 상태 및 응답 시간 점검용입니다!
KILLER TRAP • PART 2

🎯 킬러 기출 함정 플립카드 ②

💡 실전 문제 풀이 팁
• 디지털 컴퓨터와 아날로그 컴퓨터의 '주요 연산'과 '기억장치 유무'는 시험 오답 보기의 단골 소재입니다.
• 카드를 클릭하여 완벽하게 정답을 각인시키세요.
체크 포인트
• Q1: 최초의 전자계산기 에니악(ENIAC)의 방식
• Q2: 디지털 컴퓨터의 주요 연산 종류
• Q3: 아날로그 컴퓨터의 기억장치 필요성
Q1. 에니악(ENIAC)의 프로그램 내장 방식 여부
"세계 최초의 전자식 계산기인 에니악(ENIAC)은 프로그램 내장 방식을 채택하였다." (O / X?)
정답: X (에니악은 '외부 프로그램' 방식!)
에니악은 외부 배선 방식이며, 최초의 프로그램 내장 방식 계산기는 에드삭(EDSAC)입니다!
Q2. 디지털 컴퓨터의 주요 연산
"디지털 컴퓨터는 증폭 회로를 이용하여 미적분 연산을 주로 수행한다." (O / X?)
정답: X (미적분 연산은 아날로그!)
디지털 컴퓨터는 논리 회로를 이용해 산술 및 논리 연산을 수행합니다!
Q3. 아날로그 컴퓨터의 기억장치 필요 여부
"아날로그 컴퓨터는 데이터 처리를 위해 반드시 대용량 기억장치와 프로그램이 필요하다." (O / X?)
정답: X (기억장치 필요 없음!)
아날로그 컴퓨터는 실시간 계측 신호를 즉시 연산하므로 기억장치와 프로그램이 필요 없습니다!
