TOPIC 01 • HARDWARE & STORAGE

컴퓨터 5대 장치 & 스토리지 관리

1. 컴퓨터 5대 핵심 장치 구조
• 중앙처리장치 (CPU): 제어장치(지시·감독) + 연산장치(ALU) + 레지스터
• 기억장치: 주기억(RAM/ROM)과 보조기억(SSD/HDD)
• 입출력장치: 키보드·마우스(입력) / 모니터·프린터(출력)
2. SSD vs HDD 관리 핵심 원칙 ★
• SSD (반도체): 압도적 속도, 무소음, 디스크 조각 모음 금지 (수명 저하)
• HDD (자기 디스크): 대용량 보관용, 물리적 충격 주의
• 파티션 분할: [디스크 관리]에서 C:(OS)와 D:(데이터) 분리 관리
💾 스토리지 및 메모리 계층 비교
장치 구분 특징 및 속도 핵심 관리 포인트
레지스터 / 캐시 CPU 내부 극초고속 메모리 데이터 처리 병목 완화 (SRAM)
주기억장치 (RAM) 휘발성 메모리 (전원 꺼지면 소멸) 다중 작업 시 16GB 이상 권장
NVMe SSD PCIe 고속 대역폭 (반도체) TRIM 활성화, 조각모음 금지
HDD 대용량 보조 스토리지 장기 백업 및 아카이빙 전용
💡 기출 & 실무 공식: SSD는 기계적 탐색 시간이 없으므로 조각 모음이 불필요하며, 수명 보존을 위해 트림(TRIM) 최적화를 사용합니다.
TOPIC 02 • OS & SHORTCUTS

Windows 제어 & 업무 단축키 200%

1. 작업 관리자 핵심 제어 (Ctrl + Shift + Esc)
• 단축키: Ctrl + Shift + Esc
• 응답 없는 프로그램 강제 종료 및 실시간 CPU/RAM 자원 모니터링
• 시험 함정: 실행 중인 앱의 실행 순서 변경은 절대 불가!
2. 실행 창(Win + R) 필수 시스템 명령어
• regedit: 레지스트리 편집기 호출
• devmgmt.msc: 장치 관리자 (드라이버 충돌 점검)
• sysdm.cpl: 시스템 속성 (환경 변수, 고급 설정)
⌨️ 실무자가 매일 쓰는 슈퍼 단축키 TOP 4
단축키 조합 기능 및 실무 활용 팁
+ V 클립보드 기록 (복사한 텍스트/이미지 히스토리)
+ Shift + S 정밀 영역 캡처 (지정한 사각 영역 즉시 캡처)
+ D 바탕화면 바로가기 (모든 창 최소화 토글)
Alt + Tab 실행 앱 빠른 전환 (작업 창 전환)
💡 생산성 팁: + V를 누르면 이전에 복사했던 여러 항목을 선택해 붙여넣을 수 있습니다.
TOPIC 03 • SPREADSHEET & DATA

엑셀 칼퇴를 부르는 5대 필수 함수

1. 데이터 조회: VLOOKUP vs XLOOKUP ★
• VLOOKUP(기준값, 범위, 열번호, FALSE): 왼쪽 첫 열에서 기준값 탐색
• XLOOKUP: 왼쪽 탐색 한계 극복, 열 번호 대신 반환 범위 직접 지정
2. 다중 조건 통계: SUMIFS & COUNTIFS
• SUMIFS(합계범위, 조건범위1, 조건1, 조건범위2, 조건2)
• COUNTIFS(조건범위1, 조건1, 조건범위2, 조건2)
📊 실무 함수 구문 및 활용 예시
함수명 구문 공식 실무 활용 시나리오
XLOOKUP =XLOOKUP(사번, 사번열, 이름열) 사번으로 직원명/직급 즉시 조회
SUMIFS =SUMIFS(매출, 부서, "영업", 월, 10) 특정 부서의 10월 총매출 합산
COUNTIFS =COUNTIFS(점수, ">=80", 출석, ">=15") 기준 점수와 출석 동시 충족 인원수
IFERROR =IFERROR(수식, "미확인") #N/A 또는 #DIV/0! 오류 깔끔하게 숨기기
💡 참조 고정 단축키: 수식 입력 중 F4를 누르면 $A$1(절대참조)로 순환 변경됩니다.
TOPIC 04 • NETWORK & DIAGNOSTICS

TCP/IP 4대 요소 & DOS 진단 명령어

1. 인터넷 통신 필수 4대 구성 요소 ★
• IP 주소: 네트워크 상의 내 PC 고유 번호
• 서브넷 마스크: 네트워크 ID와 호스트 ID 분할 규격
• 기본 게이트웨이: 외부 인터넷으로 나가는 출입 관문 (공유기 라우터)
• DNS 서버: 문자 도메인(google.com)을 숫자 IP로 변환
2. IP 자동 할당 (DHCP)
• 공유기로부터 IP를 수동 입력 없이 동적으로 자동 할당받는 프로토콜
⚡ 네트워크 3대 진단 명령어 비교 매트릭스
명령어 핵심 키워드 장애 진단 역할 및 시험 정답
Ping 연결 상태 점검 패킷 왕복 시간(ms)과 신호 손실률 측정
Ipconfig 내 PC 정보 확인 IP 주소, 게이트웨이, MAC 주소 확인 (/all)
Tracert 경로 추적 (라우팅) 목적지 서버까지 거쳐가는 라우터 구간 추적
💡 기출 지문 정답: "원격지 컴퓨터의 네트워크 연결 상태와 신호 손실률을 점검할 때 사용하는 명령어는 Ping이다."

Q1. 작업 관리자 실행 순서 제어
"Windows 작업 관리자에서는 실행 중인 프로그램들의 실행 순서를 임의로 변경할 수 있다." (O / X?)
정답: X (실행 순서 변경 절대 불가!)
작업 관리자에서는 강제 종료 및 리소스 모니터링만 가능하며, 실행 순서 변경은 불가능합니다!
Q2. Tracert 명령어의 역할
"Tracert 명령어는 원격지 호스트와의 왕복 응답 시간과 신호 손실률을 측정한다." (O / X?)
정답: X (왕복 시간 측정은 Ping!)
패킷이 거치는 라우터를 추적하는 것은 Tracert이며, 연결 상태 및 응답 점검은 Ping입니다!
Q3. SSD 스토리지의 디스크 조각 모음
"SSD의 성능 유지를 위해 주기적으로 디스크 조각 모음을 실행하는 것이 좋다." (O / X?)
정답: X (SSD 조각 모음은 절대 금지!)
SSD는 플래시 메모리 기반이므로 조각 모음이 불필요하며, 과도한 쓰기 작업으로 수명이 단축됩니다!
